Computer scientist and full-stack developer from Gravataí, RS, Brazil.

### About me

- 🎓 Computer scientist by training.
- 🧩 I like owning a product end to end: talking to the people who use it, modeling the domain, writing the API and the front end, and running it in production.
- 📱 I started in mobile with Flutter. My first published app was for a jewelry brand, and that market stuck with me: today I build software for the stores in it.
- 🛠️ Most of my time now goes into .NET APIs and React front ends, plus the infrastructure that keeps them online.
- 🎯 I care about software that real shop owners can use without a manual: clear screens, friendly error messages, and numbers they can trust.
- 🎧 Music lover, usually coding with something playing.

### What I'm working on

**DaJoias** — a multi-tenant SaaS for jewelry stores that sell through consignment consultants.
It covers inventory, consignment kits and settlements, commissions, sales, finance, invoicing (NFC-e),
label printing and an online store for each shop.

- **API:** .NET 8, ASP.NET Core, EF Core, PostgreSQL, RabbitMQ, clean architecture, xUnit
- **Front end:** React 19, TypeScript, TanStack Start / Router / Query, Tailwind CSS, on Cloudflare
- **Infra:** Docker, Traefik, Cloudflare R2, Supabase, two servers with failover
- **Desktop:** a Windows / macOS tray agent that prints ZPL labels sent from the web app
